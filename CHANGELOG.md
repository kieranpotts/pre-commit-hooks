# Changelog

## [Unreleased]

## [0.4.0] - 2026-08-08

- Renamed `feature` to `behavior` commit message type, to match TS-9 -
  BREAKING.
- Renamed `runtime` to `quality` commit message type, to match TS-9 -
  BREAKING.

## [0.3.0] - 2026-08-08

- Renamed `performance` to `runtime` commit message type, to match TS-9 -
  BREAKING.
- Added `create`, `update`, and `delete` commit message types, matching
  TS-9's extended revision types for non-executable content repositories.

## [0.2.0] - 2026-07-07

- Rename "format" to "style" commit message type - BREAKING.
- Loosen commit message validation to allow numbers - BREAKING.

## [0.1.0] - 2026-05-20

- Updated `validate-commit-message` hook - BREAKING:
  - Removed `add:` prefix.
  - Removed `edit:` prefix.
  - Removed `remove:` prefix.
  - Removed `restructure:` prefix.

## [0.0.0] - 2026-05-14

- Added `validate-commit-message` hook.
